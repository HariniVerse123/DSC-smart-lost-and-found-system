# Contributing to DSC Smart Lost and Found System

Thank you for your interest in contributing. This project is open to improvements from beginners and experienced contributors.

## Ways to Contribute

You can help by:

- Improving the C code structure and readability.
- Adding stronger input validation.
- Improving the smart search and match score logic.
- Adding sorting or filtering options.
- Improving file storage and error handling.
- Fixing bugs.
- Updating documentation.
- Adding sample test cases or usage examples.

## Contribution Workflow

1. Fork this repository.
2. Create a new branch for your change.
3. Make your edits.
4. Test the C program before submitting.
5. Open a pull request with a clear description of your change.

## Build Before Submitting

Use GCC or another C compiler to check that the program builds successfully.

```bash
gcc main.c -o lost_found
./lost_found
```

On Windows, you can use:

```bash
gcc main.c -o lost_found.exe
./lost_found.exe
```

## Pull Request Guidelines

Please include:

- A short title that explains the change.
- A description of what you changed and why.
- Screenshots or sample input/output if the change affects program behavior.
- Notes about any known limitations.

## Coding Guidelines

- Keep the code simple and readable.
- Use meaningful variable and function names.
- Avoid unnecessary global variables when possible.
- Add comments only where they make the logic easier to understand.
- Do not remove existing features unless the pull request explains why.

## Reporting Issues

If you find a bug or have an idea, open an issue with:

- What happened.
- What you expected to happen.
- Steps to reproduce the problem.
- Your operating system and compiler, if relevant.

## Be Respectful

Keep discussions friendly, helpful, and focused on improving the project.
